# Responsive Landing Page

## Overview

This project is a responsive landing page developed using HTML and CSS. It is designed for a web development learning platform and demonstrates modern UI design, responsive layouts, and clean styling.

Developed as part of the Synent Technologies Web Development Internship Program.

## Features

* Responsive design
* Hero section
* Features section
* About section
* Contact section
* Footer
* Modern glassmorphism effects
* Hover animations

## Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)

## Project Structure

* index.html
* style.css

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
